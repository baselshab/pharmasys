# Backend Setup Plan

## Objective
Set up a Node.js + TypeScript backend with Prisma ORM and PostgreSQL for the PharmaSys pharmacy management system.

## Technology Stack
- **Runtime**: Node.js
- **Language**: TypeScript
- **ORM**: Prisma
- **Database**: PostgreSQL

## Implementation Steps

### 1. Initialize Backend Project
```bash
mkdir backend && cd backend
npm init -y
npm install typescript @types/node ts-node nodemon prisma @prisma/client -D
npx tsc --init
```

### 2. Configure TypeScript
Create `tsconfig.json` with appropriate settings for Node.js and Prisma.

### 3. Set Up Prisma
```bash
npx prisma init
```
- Configure datasource in `prisma/schema.prisma`
- Define all models matching the frontend schema

### 4. Database Schema (Prisma Models)

Based on `frontend/src/db/migrations.ts` and `seedData.ts`:

| Model | Description |
|-------|------------|
| Pharmacy | Pharmacy entity |
| User | System users |
| UserRole | Roles (admin, pharmacist, cashier, manager) |
| Category | Product categories |
| Product | Pharmaceuticals with pricing, barcode |
| ProductBatch | Batch tracking with expiry (FEFO) |
| StockAdjustment | Inventory adjustments |
| Supplier | Supplier management |
| PurchaseOrder | PO system |
| PurchaseOrderItem | PO line items |
| Customer | Customer records |
| Sale | Sales transactions |
| SaleItem | Sale line items |
| SalePayment | Payment methods per sale |
| Branch | Multi-branch support |
| BranchUser | Branch-user assignments |
| RolePermission | RBAC permissions |
| CustomerDebt | Credit tracking |
| Attendance | Staff attendance |
| AuditLog | Activity logging |
| SyncLog | Offline sync queue |

### 5. Create Prisma Schema
Map SQLite schema to Prisma schema with proper relations and constraints.

### 6. Generate Client & Push Schema
```bash
npx prisma generate
npx prisma db push
```

### 7. Seed Script
Create `prisma/seed.ts` based on `frontend/src/db/seedData.ts`.

### 8. Project Structure
```
backend/
├── src/
│   ├── index.ts         # Entry point
│   ├── db.ts           # Prisma client
│   └── ...
├── prisma/
│   ├── schema.prisma
│   └── seed.ts
├── package.json
└── tsconfig.json
```
